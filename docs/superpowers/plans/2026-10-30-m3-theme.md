# M3 实施计划：`theme` 包

依据：[设计稿](../specs/2026-10-30-livemark-design.md) §4。`theme` 是纯 Go 包，只依赖标准库，不碰编辑器代码，所以不用等 M0.5。

每一步先写测试，再写实现，`go test ./theme` 通过后再进入下一步。

| # | 内容 | 文件 |
|---|---|---|
| 1 | 词法：CSS Syntax Level 3 的子集，带偏移（诊断换算成行列号）；注释、字符串与转义、数字/百分比/尺寸、`url()`、函数、at 关键字 | `token.go` |
| 2 | 语法：规则、声明、`!important`、`@media`（`prefers-color-scheme`）、`@font-face`、其他 at 规则的跳过；错误恢复与诊断 | `parse.go`、`diag.go` |
| 3 | 元素与词汇表：`Element`、状态位、全部类型/类/属性/伪元素；按编辑距离给建议 | `element.go`、`vocab.go` |
| 4 | 选择器：解析、特异性、对元素路径的匹配（后代、子、`:not()`、伪元素） | `selector.go` |
| 5 | 值：颜色（与 MyGo 相同的 RGBA 字节和舍入）、命名颜色、`color-mix()`；长度与 `calc()`/`min()`/`max()`/`clamp()` | `color.go`、`named.go`、`value.go` |
| 6 | 属性表：继承、初始值、解析、适用元素、简写展开 | `props.go` |
| 7 | 层叠与计算：`Theme` 的层、`Resolver`、`Node` 前缀树、排序、继承、`var()` 与循环检测、传播（背景、装饰线、基线偏移、透明度）、伪元素 | `cascade.go`、`computed.go` |
| 8 | `default.css`：按设计稿 §5.2 的清单还原今天的外观；解析零诊断；关键计算值有单测 | `default.css`、`default.go` |

完成标准：`go test ./theme` 通过；`go vet` 干净；`default.css` 解析无诊断；包内没有对 MyGo 的依赖。
